Proto is a script to help in writing programs. It looks up code snippets in a
database of keyword - snippet pairings and inserts the corresponding snippet in
the file being edited.

Copy the file "Proto.vbs" to the VBScript subfolder of PSPad's Script folder.
Copy the folder "Proto" to the PSPad Editor folder. This provides Proto files
for Rexx programs and VBS programs. These files have some information at the
beginning that should help you create your own proto files if you wish.

Click on Recompile scripts in the PSPad Script Menu if PSPad is already open.
This should add "Proto" to the "RWAddons" submenu in the Scripts menu.
